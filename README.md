# cemc-oper Compass

**cemc-oper 软件开发与维护指南**

Compass 汇总 cemc-oper 项目组的软件开发约定与维护实践，帮助开发者保持一致的项目说明，也帮助使用者了解项目状态和使用预期。

指南从实际需要出发逐步完善。目前包含项目成熟度分类，后续按需增加其他主题。

## 指南目录

- [项目成熟度](project-maturity/README.md)：分类含义与使用说明。
- [成熟度徽章](project-maturity/badges.md)：徽章预览与可复制的 Markdown 代码。

## 使用与维护

各项目可引用对应指南，并结合自身情况补充说明。成熟度由项目开发者自行设置，项目状态变化时更新即可。

指南的补充和修改可以通过 Issue 或 Pull Request 提出。
