# 项目成熟度

cemc-oper 使用以下分类说明软件项目当前的发展和维护状态，帮助使用者理解项目的功能完整性、稳定程度和使用预期。

分类由项目开发者根据实际情况自行选择，无需评分、评审或提交证明材料。项目状态变化时，由开发者更新对应标识。

## 分类概览

| 分类 | 中文名称 | 说明 |
| --- | --- | --- |
| [Sandbox](#sandbox) | 试验级 | 概念验证，功能可能不完整，接口和实现可能频繁变化。 |
| [Emerging](#emerging) | 探索级 | 已有明确开发方向，处于早期开发阶段。 |
| [Incubating](#incubating) | 成长级 | 核心功能基本完整，已在内部实际应用，仍在持续完善。 |
| [Graduated](#graduated) | 成熟级 | 已在业务系统中稳定使用，主要功能和接口较为稳定。 |
| [Archived](#archived) | 归档级 | 已停止维护，保留历史代码和文档供参考。 |

## Sandbox

![Maturity-Sandbox](https://img.shields.io/badge/Maturity-Sandbox-F9D71C)

**试验级。** 用于概念验证或技术探索的实验性项目。功能可能不完整，接口、实现和项目方向可能频繁变化。

适合研究与试验，使用时应预期较大的调整。

## Emerging

![Maturity-Emerging](https://img.shields.io/badge/Maturity-Emerging-A259FF)

**探索级。** 已有明确的开发方向，处于早期开发阶段，主要功能和接口仍在逐步形成。

可以尝试使用，但应关注功能缺失、已知限制和不兼容变更。

## Incubating

![Maturity-Incubating](https://img.shields.io/badge/Maturity-Incubating-56B4E9)

**成长级。** 核心功能基本完整，已在内部实际应用，主要接口逐步稳定，项目仍在持续完善。

使用时建议固定版本，并关注版本更新和兼容性说明。

## Graduated

![Maturity-Graduated](https://img.shields.io/badge/Maturity-Graduated-97CA00)

**成熟级。** 已在业务系统中稳定使用，主要功能和接口较为稳定。

具体适用的功能、版本和运行环境以项目文档为准，升级时仍需结合实际使用场景验证。

## Archived

![Maturity-Archived](https://img.shields.io/badge/Maturity-Archived-FE7D37)

**归档级。** 已停止维护，保留历史代码和文档供参考。项目可能已被替代、合并，或不再继续开发。

不建议新增依赖；已有使用者可根据项目说明评估替代方案或自行维护。

Archived 表示维护状态，任何阶段的项目都可以归档，并不表示比 Graduated 更高的成熟程度。

## 使用说明

- 在项目 README 中选择并添加一个对应的[成熟度徽章](badges.md)，链接到本文的具体分类。
- 开发者根据项目实际情况自行设置分类，不要求逐级变更。
- 如需说明特殊情况，可在项目 README 中补充简短文字，无固定格式要求。
- 分类用于沟通项目状态，不作为正式评估、认证或服务承诺，也不表示所有功能和运行环境均已验证。
